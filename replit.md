# TV Corporativa SENAI

## Visão geral

Aplicação Next.js para gerenciar conteúdos, avisos, instituições e dispositivos
de TV corporativa.

## Infraestrutura

- PostgreSQL gerenciado pelo Replit via `DATABASE_URL`
- Autenticação simples própria com cookie HTTP-only assinado
- Uploads locais em `public/uploads`
- Workflow principal: `npm run dev` na porta 5000
